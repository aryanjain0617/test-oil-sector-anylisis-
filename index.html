Technical stop losses sit on the underlying chart via Supertrend. Delta converts that underlying risk into an exact option exit price.

Underlying Risk = | Current Stock Price - Supertrend Price |
Option Contract Risk = Underlying Risk x Option Delta
Option Stop Loss Price = Entry Option Premium +/- Option Risk (+ for sold options, - for bought options)

import numpy as np
import pandas as pd

class AutoSectorQuantEngine:
    def __init__(self, watchlist=None):
        self.watchlist = watchlist or ['TATAMOTORS', 'M&M', 'MARUTI', 'BAJAJ-AUTO']

    def calculate_rsi(self, df, period=14):
        delta = df['close'].diff()
        gain = (delta.where(delta > 0, 0)).rolling(window=period).mean()
        loss = (-delta.where(delta < 0, 0)).rolling(window=period).mean()
        rs = gain / loss.replace(0, np.nan)
        return (100 - (100 / (1 + rs))).fillna(50)

    def calculate_ivp(self, current_iv, iv_history_52wk):
        low_iv, high_iv = np.min(iv_history_52wk), np.max(iv_history_52wk)
        if high_iv == low_iv:
            return 50.0
        return float(((current_iv - low_iv) / (high_iv - low_iv)) * 100.0)

    def calculate_option_stop_loss(self, spot_price, supertrend_price, option_premium, delta=0.50, is_earnings=False):
        underlying_risk = abs(spot_price - supertrend_price)
        option_risk = underlying_risk * delta
        if is_earnings:
            option_risk *= 1.10  # 10% Vega/Gamma slippage buffer
        return max(0.10, round(option_premium - option_risk, 2))

Core indicators (RSI, Supertrend, IVP, Triple Supertrend), the trading calendar with Cycle A / B windows and exit plans, the dual-exit checker and the Crude Regime Gate. This part opens the OilSectorQuantEngine class; Parts 3–5 continue the same class.

class OilSectorQuantEngine:
    """Oil, Gas, Aviation & Paints engine. 1h candles, NRML, next-month expiry.
    Pass COMPLETED 1h candles only (columns: open, high, low, close)."""

    def __init__(self, config=None, holidays=None, fno_list=None):
        self.cfg = config or OilConfig()
        self.holidays = set(holidays or [])
        self.watchlist = [s for s in UNIVERSE if fno_list is None or s in fno_list]

    # ---------- indicators ----------
    def calculate_rsi(self, df, period=14):
        delta = df["close"].diff()
        gain = delta.where(delta > 0, 0).rolling(window=period).mean()
        loss = (-delta.where(delta < 0, 0)).rolling(window=period).mean()
        rs = gain / loss.replace(0, np.nan)
        return (100 - (100 / (1 + rs))).fillna(50)

    def calculate_supertrend(self, df, period=100, multiplier=1.65):
        """Returns (supertrend_line, direction). direction: -1 = Green (bullish),
        +1 = Red (bearish), 0 = warm-up. Same convention as the Auto Sector manual."""
        high, low, close = df["high"], df["low"], df["close"]
        prev_close = close.shift(1)
        tr = pd.concat([high - low, (high - prev_close).abs(),
                        (low - prev_close).abs()], axis=1).max(axis=1)
        atr = tr.rolling(window=period).mean()
        hl2 = (high + low) / 2
        b_ub = (hl2 + multiplier * atr).to_numpy()
        b_lb = (hl2 - multiplier * atr).to_numpy()
        c, mid, n = close.to_numpy(), hl2.to_numpy(), len(df)
        f_ub, f_lb = np.full(n, np.nan), np.full(n, np.nan)
        st, direction = np.full(n, np.nan), np.zeros(n, dtype=int)
        first = period - 1
        if n <= first:
            return pd.Series(st, index=df.index), pd.Series(direction, index=df.index)
        f_ub[first], f_lb[first] = b_ub[first], b_lb[first]
        direction[first] = -1 if c[first] > mid[first] else 1
        st[first] = f_lb[first] if direction[first] == -1 else f_ub[first]
        for i in range(first + 1, n):
            f_ub[i] = b_ub[i] if (b_ub[i] < f_ub[i - 1] or c[i - 1] > f_ub[i - 1]) else f_ub[i - 1]
            f_lb[i] = b_lb[i] if (b_lb[i] > f_lb[i - 1] or c[i - 1] < f_lb[i - 1]) else f_lb[i - 1]
            if direction[i - 1] == 1:
                direction[i] = -1 if c[i] > f_ub[i] else 1
            else:
                direction[i] = 1 if c[i] < f_lb[i] else -1
            st[i] = f_lb[i] if direction[i] == -1 else f_ub[i]
        return pd.Series(st, index=df.index), pd.Series(direction, index=df.index)

    def evaluate_triple_supertrend(self, df):
        dirs = [self.calculate_supertrend(df, p, m)[1].iloc[-1] for p, m in self.cfg.triple_st]
        return all(d == -1 for d in dirs), all(d == 1 for d in dirs)

    def calculate_ivp(self, current_iv, iv_history_52wk):
        low_iv, high_iv = np.min(iv_history_52wk), np.max(iv_history_52wk)
        if high_iv == low_iv:
            return 50.0
        return float(((current_iv - low_iv) / (high_iv - low_iv)) * 100.0)

    # ---------- trading calendar ----------
    @staticmethod
    def last_tuesday(year, month):
        d = date(year, month, calendar.monthrange(year, month)[1])
        while d.weekday() != 1:
            d -= timedelta(days=1)
        return d

    def is_trading_day(self, d):
        return d.weekday() < 5 and d not in self.holidays

    def _prev_trading_day(self, d):
        while not self.is_trading_day(d):
            d -= timedelta(days=1)
        return d

    def _next_trading_day(self, d, strict=False):
        if strict:
            d += timedelta(days=1)
        while not self.is_trading_day(d):
            d += timedelta(days=1)
        return d

    @staticmethod
    def next_month(d):
        return (d.year + (d.month == 12), d.month % 12 + 1)

    def calendar_state(self, d, expiry_dates=None):
        """Phase, cycle and entry permission for a date (see calendar manual)."""
        c, day = self.cfg, d.day
        if day <= 7:
            phase, cycle = "CATALYST_RELEASE", "B"
        elif c.entry_a[0] <= day <= c.entry_a[1]:
            phase, cycle = "ENTRY_WINDOW_A", "A"
        elif day <= c.hard_exit_a_day:
            phase, cycle = "REPORT_WINDOW", "A"
        elif day < c.entry_b[0]:
            phase, cycle = "COOL_DOWN", None
        elif day <= c.entry_b[1]:
            phase, cycle = "ENTRY_WINDOW_B", "B"
        else:
            phase, cycle = "HOLD_AND_TRAIL", "B"
        expiry = (expiry_dates or {}).get((d.year, d.month), self.last_tuesday(d.year, d.month))
        entry_ok = (phase.startswith("ENTRY_WINDOW") and self.is_trading_day(d) and d != expiry)
        return {"phase": phase, "cycle": cycle, "entry_allowed": entry_ok}

    def exit_plan(self, cycle, entry_date, events=None):
        """Scale-out date and final hard-exit deadline. events keys (date values):
        'opec_plus', 'opec_momr', 'iea_omr'."""
        events, c = events or {}, self.cfg
        if cycle == "A":
            deadline = self._prev_trading_day(
                date(entry_date.year, entry_date.month, c.hard_exit_a_day))
            reports = [events[k] for k in ("opec_momr", "iea_omr") if events.get(k)]
            scale = self._next_trading_day(max(reports), strict=True) if reports else deadline
            scale = min(scale, deadline)
        else:
            y, m = self.next_month(entry_date)
            cap = self._prev_trading_day(date(y, m, c.hard_exit_b_day))
            meet = events.get("opec_plus")
            deadline = min(self._next_trading_day(meet, strict=True), cap) if meet else cap
            scale = deadline
        return {"scale_out_date": scale, "deadline": deadline,
                "scale_fraction": c.scale_out_fraction}

    def check_exit(self, pos, df, today, events=None):
        """Dual exit logic: Supertrend reversal OR calendar hard exit, whichever is first."""
        _, d = self.calculate_supertrend(df, self.cfg.st_period, self.cfg.st_mult)
        last = d.iloc[-1]
        if (pos.side == "LONG" and last == 1) or (pos.side == "SHORT" and last == -1):
            return {"action": "EXIT_ALL", "reason": "Supertrend reversal (overrides calendar)"}
        plan = self.exit_plan(pos.cycle, pos.entry_date, events)
        if today > plan["deadline"]:
            return {"action": "EXIT_ALL", "reason": "Calendar hard exit overdue"}
        if today >= plan["scale_out_date"] and not pos.scaled_out:
            return {"action": "SCALE_OUT", "fraction": plan["scale_fraction"],
                    "flatten_by_close": today >= plan["deadline"]}
        if today >= plan["deadline"]:
            return {"action": "EXIT_ALL", "reason": "Calendar hard exit by close"}
        return {"action": "HOLD"}

    # ---------- crude regime gate ----------
    def read_crude_regime(self, crude_df):
        """Brent / MCX Crude 1h: Close above Supertrend = BULL, below = BEAR."""
        _, d = self.calculate_supertrend(crude_df, self.cfg.st_period, self.cfg.st_mult)
        last = d.iloc[-1]
        return "BULL" if last == -1 else "BEAR" if last == 1 else "UNKNOWN"

    def gate_direction(self, symbol, regime):
        """The only direction a symbol may trade under the current crude regime."""
        if regime not in ("BULL", "BEAR"):
            return None
        follows_crude = SECTOR_SENSITIVITY[UNIVERSE[symbol]] > 0
        return "BULLISH" if (regime == "BULL") == follows_crude else "BEARISH"

The decision tree: calendar gatekeeper, RSI + Supertrend triggers, crude gate, IVP-based strategy selection, results-date and Wednesday safeguards, and the quarterly earnings playbook.

    def generate_trading_signal(self, symbol, df, crude_df, current_iv, iv_history, now,
                                events=None, results_date=None, open_positions=None):
        c = self.cfg
        if symbol not in self.watchlist:
            return {"symbol": symbol, "action": "NOT_IN_UNIVERSE"}
        cal = self.calendar_state(now.date())
        sig = {"symbol": symbol, "timestamp": now, "phase": cal["phase"], "cycle": cal["cycle"]}

        # 1) Calendar gatekeeper: no entry outside Window A / B
        if not cal["entry_allowed"]:
            sig.update(action="STANDBY", reason="Outside entry window or expiry day")
            return sig
        if any(p.symbol == symbol for p in (open_positions or [])):
            sig.update(action="BLOCKED", reason="Open position exists (no A/B overlap)")
            return sig

        # 2) Technical triggers on the stock chart
        if len(df) < c.st_period + 2:
            sig.update(action="INSUFFICIENT_DATA")
            return sig
        rsi = self.calculate_rsi(df, c.rsi_period).iloc[-1]
        st, direction = self.calculate_supertrend(df, c.st_period, c.st_mult)
        now_dir, prev_dir = direction.iloc[-1], direction.iloc[-2]
        bull = rsi > c.rsi_bull and now_dir == -1 and (prev_dir == 1 or not c.require_cross)
        bear = rsi < c.rsi_bear and now_dir == 1 and (prev_dir == -1 or not c.require_cross)
        if not (bull or bear):
            sig.update(action="NO_TRADE_SETUP", rsi=round(float(rsi), 2))
            return sig
        side = "BULLISH" if bull else "BEARISH"

        # 3) Crude gate: conflicting signals are skipped
        regime = self.read_crude_regime(crude_df)
        sig.update(crude_regime=regime, direction=side)
        if self.gate_direction(symbol, regime) != side:
            sig.update(action="SKIPPED_BY_CRUDE_GATE")
            return sig

        # 4) Event, volatility and sizing context
        ivp = self.calculate_ivp(current_iv, iv_history)
        triple_green, triple_red = self.evaluate_triple_supertrend(df)
        plan = self.exit_plan(cal["cycle"], now.date(), events)
        results_in_hold = bool(results_date and now.date() <= results_date <= plan["deadline"])
        naked_ok = cal["cycle"] == "B" and not results_in_hold   # naked only in catalyst window
        wednesday = now.weekday() == 2                           # EIA gap lands Thursday open
        sig.update(action="ENTRY_SIGNAL", spot=float(df["close"].iloc[-1]),
                   st_stop=float(st.iloc[-1]), rsi=round(float(rsi), 2), ivp=round(ivp, 1),
                   naked_allowed=naked_ok, size_factor=0.5 if wednesday else 1.0,
                   exit_plan=plan, notes=[])

        # 5) Routing: direct futures, synthetic futures, then volatility selector
        if bull:
            sig["futures_action"] = "BUY_NEXT_MONTH_FUTURES_NRML"
            sig["synthetic_action"] = ["BUY_ATM_CE_NEXT_MONTH", "SELL_ATM_PE_NEXT_MONTH"]
            sell_name = "SELL_ATM_PUT_OR_BULL_PUT_CREDIT_SPREAD" if naked_ok else "BULL_PUT_CREDIT_SPREAD"
            buy_name, buy_ok = "BUY_ATM_CALL_OR_BULL_CALL_DEBIT_SPREAD", triple_green
        else:
            sig["futures_action"] = "SELL_NEXT_MONTH_FUTURES_NRML"
            sig["synthetic_action"] = ["BUY_ATM_PE_NEXT_MONTH", "SELL_ATM_CE_NEXT_MONTH"]
            sell_name = "SELL_ATM_CALL_OR_BEAR_CALL_CREDIT_SPREAD" if naked_ok else "BEAR_CALL_CREDIT_SPREAD"
            buy_name, buy_ok = "BUY_ATM_PUT_OR_BEAR_PUT_DEBIT_SPREAD", triple_red
        if ivp > c.ivp_split:
            sig["options_strategy"] = sell_name
            sig["edge"] = "Vega Collapse + Theta Decay + Delta"
        else:
            sig["options_strategy"] = buy_name if buy_ok else "WAIT_FOR_TRIPLE_ST_CONFIRMATION"
            sig["edge"] = "Gamma Acceleration + Convexity"

        if results_in_hold:
            sig["synthetic_action"] = None
            sig["notes"].append("Results inside hold: synthetic (naked short leg) blocked; "
                                "futures follow Supertrend/calendar; use defined-risk spreads.")
        if wednesday:
            sig["notes"].append("Wednesday: halve size on short-option legs or use spreads.")
        sig["notes"].append("Crude trades while NSE is shut: stops cannot protect opening gaps.")
        return sig

    def scan_universe(self, data, crude_df, now, iv_inputs, **kw):

    def earnings_playbook(self, days_to_results, ivp, ivp_rising):

8. ALGORITHMIC PYTHON ENGINE — CRUDE-DIVERGENCE PAIR TRADES (MEAN REVERSION)

Strategy 3. Spread = Upstream − β × Other, Z-score on a 60-day window, entries beyond |Z| 2.0 (2.2 for ONGC / BPCL), exit at |Z| ≤ 0.5, 15 trading days or an extreme-Z stop beyond 3.5.

    def pair_zscore(self, up_close, other_close):
        """Spread = Upstream - beta x Other, Z against the trailing 60-day mean and sigma."""
        w = self.cfg.z_window
        both = pd.concat([up_close, other_close], axis=1, join="inner").dropna().iloc[-w:]
        if len(both) < w:
            return None
        y, x = both.iloc[:, 0], both.iloc[:, 1]
        beta = float(np.cov(y, x, ddof=1)[0, 1] / np.var(x, ddof=1))
        spread = y - beta * x
        sigma = spread.std(ddof=1)
        if sigma == 0 or np.isnan(sigma):
            return None
        return {"beta": beta, "z": float((spread.iloc[-1] - spread.mean()) / sigma)}

    def pair_signal(self, up_sym, other_sym, up_close, other_close, vix,
                    open_pair=None, open_positions=None):
        """open_pair: {'direction': 'LONG_SPREAD'|'SHORT_SPREAD', 'days_held': int}.
        open_positions: {symbol: 'BULLISH'|'BEARISH'} from Strategy 1 / 2."""
        c = self.cfg
        zr = self.pair_zscore(up_close, other_close)
        if zr is None:
            return {"action": "INSUFFICIENT_DATA"}
        z, beta = zr["z"], zr["beta"]
        out = {"pair": (up_sym, other_sym), "z": round(z, 2), "beta": round(beta, 3)}
        if open_pair:                                       # exit logic for a live pair
            if abs(z) > c.z_stop:
                return {**out, "action": "STOP_OUT", "reason": "|Z| > 3.5: trend, not reversion"}
            if abs(z) <= c.z_exit:
                return {**out, "action": "EXIT_TARGET", "reason": "Z back inside +/-0.5"}
            if open_pair["days_held"] >= c.pair_max_days:
                return {**out, "action": "EXIT_TIME", "reason": "15 trading days"}
            return {**out, "action": "HOLD"}
        thr = c.z_entry_core if (up_sym, other_sym) in CORE_PAIRS else c.z_entry
        if abs(z) > c.z_stop:
            return {**out, "action": "NO_ENTRY", "reason": "|Z| beyond 3.5"}
        if abs(z) < thr:
            return {**out, "action": "NO_TRADE_SETUP", "threshold": thr}
        short_spread = z > 0                                # rich upstream vs the other leg
        long_leg, short_leg = (other_sym, up_sym) if short_spread else (up_sym, other_sym)
        for sym, bias in (open_positions or {}).items():   # no opposing Strategy 1 exposure
            if (sym == long_leg and bias == "BEARISH") or (sym == short_leg and bias == "BULLISH"):
                return {**out, "action": "BLOCKED", "reason": f"Opposite Strategy 1 in {sym}"}
        out.update(action="ENTRY_SIGNAL",
                   direction="SHORT_SPREAD" if short_spread else "LONG_SPREAD",
                   long_leg=long_leg, short_leg=short_leg, threshold=thr)
        if vix > c.vix_hedge_level:
            out["structure"] = {long_leg: "BULL_PUT_SPREAD", short_leg: "BEAR_CALL_SPREAD"}
        else:
            out["structure"] = {long_leg: "BUY_FUT_NRML", short_leg: "SELL_FUT_NRML"}
        return out

    @staticmethod
    def size_pair_legs(price_up, lot_up, price_other, lot_other, beta, lots_up=1, mode="cash"):
        """Beta-neutral sizing. mode 'cash' = equal rupee value; 'beta' = beta shares."""
        shares_up = lots_up * lot_up
        if mode == "cash":
            target = shares_up * price_up / price_other
        else:
            target = shares_up * beta
        return {"lots_up": lots_up, "lots_other": max(1, int(round(target / lot_other)))}

    @staticmethod
    def nifty_hedge_lots(residual_beta_value, nifty_price, nifty_lot):
        """Positive residual market exposure (Rs) -> negative lots (sell Nifty futures)."""
        return -int(round(residual_beta_value / (nifty_price * nifty_lot)))

    def calculate_option_stop_loss(self, spot, supertrend, premium, delta=None,
                                   is_sold=False, is_earnings=False):
        """Delta translation. Sold option: stop ABOVE entry premium; bought: BELOW."""
        delta = self.cfg.delta_atm if delta is None else delta
        risk = abs(spot - supertrend) * delta
        if is_earnings:
            risk *= 1 + self.cfg.earnings_buffer       # 5%-10% Vega/Gamma buffer
        stop = premium + risk if is_sold else max(0.10, premium - risk)
        return round(stop, 2)

    @staticmethod
    def atm_strike(spot, strike_step):
        return round(spot / strike_step) * strike_step

    def build_basket(self, sig, symbol, lot_size, lots, strike_step, structure="FUTURES"):
        """Turn an ENTRY_SIGNAL into order legs. BUY legs are listed first."""
        now = sig["timestamp"]
        y, m = self.next_month(now.date())
        qty = int(lots * lot_size * sig.get("size_factor", 1.0))
        qty = max(lot_size, qty - qty % lot_size)
        bull = sig["direction"] == "BULLISH"
        if structure == "FUTURES":
            return [OrderLeg(symbol, "FUT", "BUY" if bull else "SELL", qty, y, m)]
        if structure == "SYNTHETIC":
            if not sig.get("synthetic_action"):
                raise ValueError("Synthetic blocked for this signal")
            k = self.atm_strike(sig["spot"], strike_step)
            if bull:
                return [OrderLeg(symbol, "CE", "BUY", qty, y, m, k),
                        OrderLeg(symbol, "PE", "SELL", qty, y, m, k)]
            return [OrderLeg(symbol, "PE", "BUY", qty, y, m, k),
                    OrderLeg(symbol, "CE", "SELL", qty, y, m, k)]
        raise ValueError("structure must be FUTURES or SYNTHETIC")

    def validate_legs(self, legs, today):
        y, m = self.next_month(today)
        for leg in legs:
            if leg.product != self.cfg.product:
                raise ValueError(f"{leg.product} blocked: only NRML allowed (MIS forbidden)")
            if (leg.expiry_year, leg.expiry_month) != (y, m):
                raise ValueError("Only next-month expiry contracts may be traded")

    def execute_basket(self, broker, legs, today, sync_window_sec=5.0, alert=print):
        """BUY leg first, then SELL, inside one sync window. Any failure -> flatten fills."""
        self.validate_legs(legs, today)
        ordered = sorted(legs, key=lambda l: 0 if l.side == "BUY" else 1)
        filled, t0 = [], time.monotonic()
        for leg in ordered:
            res = broker.place_order(leg)
            late = (time.monotonic() - t0) > sync_window_sec
            if res.get("status") == "FILLED" and not late:
                filled.append(leg)
                continue
            alert(f"LEG FAILURE on {leg.symbol} {leg.instrument} {leg.side}: flattening")
            for f in filled:
                flat = OrderLeg(f.symbol, f.instrument, "SELL" if f.side == "BUY" else "BUY",
                                f.qty, f.expiry_year, f.expiry_month, f.strike)
                broker.place_order(flat)
            return {"status": "ABORTED_FLATTENED", "failed_leg": leg}
        return {"status": "FILLED", "legs": ordered}

11. DETAILED ENGLISH STRATEGY & TACTICAL PLAYBOOK

A. Monthly Oil Catalyst Playbook

Public-sector OMCs revise ATF prices on the 1st and OPEC+ usually decides in the first days of the month; OPEC and IEA monthly reports land around the 10th–14th. Cycle B enters between the 21st and 26th when IV tends to be building, holds Next Month contracts in NRML through month-end, and on the first full session after the OPEC+ meeting exits 70%–80% to harvest the post-event IV crush, with the balance flat by that close (latest the 7th). Cycle A enters on the 8th–10th after the early-month catalysts, when IVP is often below 50 and debit structures are favoured, and is flat by the close of the 16th.

B. Quarterly Earnings Playbook

Earnings create binary gap risk. 7 to 10 days before results the system buys options on rising IVP and exits one day prior. 1 to 2 days before results it sells only defined-risk credit spreads, and only when IVP > 70. Naked option selling is forbidden into results; if a results date falls inside a held trade, synthetic positions are blocked and futures follow Supertrend / calendar exits.

C. Weekly Oil Rhythm

API inventory estimates arrive Tuesday night; the EIA report lands about 8–9 pm IST on Wednesday, after the Indian close, so NRML positions absorb it as a Thursday opening gap. On Wednesdays the engine halves size on any structure with a short option leg (or the operator converts to spreads). Sunday OPEC+ meetings create the largest scheduled weekend gap.

D. Crude-Divergence Pair Trades

When the upstream spread against a downstream, aviation or paints name stretches beyond |Z| 2.0 (2.2 for ONGC / BPCL), the system trades the reversion with beta-neutral legs, using spreads instead of naked futures when India VIX > 20. It exits when Z returns inside ±0.5 or after 15 trading days, and stops out if |Z| widens beyond 3.5 because that signals a trend, not a reversion.
